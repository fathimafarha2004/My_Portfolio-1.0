## ✨ Features

- 🌓 **Dynamic Light & Dark Theme Toggle:** Preference persistence saved in LocalStorage.
- 📱 **Fully Responsive Layout:** Optimized for mobile phones, tablets, laptops, and wide screens.
- 💻 **Project Showcase with Modals:** Interactive popups detailing technologies used and features.
- 📋 **Copy Email Clipboard Feature:** One-click email copying with visual toast notifications.
- 🎨 **Modern Aesthetics & Glassmorphic Micro-Animations:** Clean typography (Outfit & Plus Jakarta Sans fonts).
- 📑 **CV / Resume Download Handler:** Smooth handling for user resume files.

## 🌐 Live Deployment Instructions

### Option 1: Deploy on Vercel (Recommended)
1. Go to [Vercel](https://vercel.com/) and sign in with GitHub.
2. Click **"Add New Project"** -> **"Import Git Repository"**.
3. Select this `portfolio` repository.
4. Click **Deploy**. Your site will be live instantly with a free SSL domain!

### Option 2: Deploy on GitHub Pages
1. Push this code to GitHub on the `main` branch.
2. Go to Repository **Settings** -> **Pages**.
3. Under **Build and deployment**, select `Deploy from a branch`.
4. Choose Branch: `main` / `root` and click **Save**.
